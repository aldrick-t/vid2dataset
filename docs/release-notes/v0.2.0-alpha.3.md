# vid2dataset2 Alpha 3

`v0.2.0-alpha.3` is a public alpha update to the vid2dataset2 Rust + Tauri
rewrite. It includes desktop form validation improvements and release workflow
updates on top of Alpha 2.

## Highlights

- Numeric settings in the desktop app now support clearing and editing values
  without silently replacing incomplete input. The app validates whole-number
  ranges and disables extraction until all required numeric settings are valid.
- Crop dimensions and sampling settings receive clearer validation before a
  job can be queued.
- The release flow validates the selected tag and builds the exact tagged
  commit from the default branch.

## Desktop distribution

Public release artifacts target:

- macOS ARM64 and x64: DMG installers and zipped `.app` bundles.
- Windows x64: MSI installer and Windows bundle artifacts.
- Linux x64: AppImage and deb packages.

Packaged applications include redistributable LGPL-compatible FFmpeg and
ffprobe binaries. This release uses FFmpeg `8.1.2` with statically linked zlib
`1.3.2`; the app does not download FFmpeg on first launch or install it
globally. Release artifacts include SHA-256 checksums. Alpha builds may be
unsigned, so macOS and Windows can show an operating-system security warning
on first launch.

## CLI

Run the command-line interface from the workspace:

```bash
cargo run -p vid2dataset -- doctor
cargo run -p vid2dataset -- inspect path/to/video.mp4
cargo run -p vid2dataset -- extract \
  --input path/to/video.mp4 \
  --output output/dataset \
  --every-n-frames 8 \
  --resize 640x640 \
  --format png \
  --manifest jsonl,csv
```

Use `cargo run -p vid2dataset -- profiles import` to migrate a legacy YAML
configuration into the new job model. Run `presets list` to inspect the
available built-in presets.

## Known limitations

- This is an alpha release, not a signed stable production release.
- Hosted web/server processing is not included.
- COCO and YOLO annotation exports are deferred; the app writes image outputs
  and traceability manifests.
- Source builds require Rust, Node.js/npm, Tauri system prerequisites, and
  FFmpeg/ffprobe available through explicit paths, environment variables, or
  `PATH`. Packaged desktop builds include their own media tools.
