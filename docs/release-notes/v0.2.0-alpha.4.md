# vid2dataset2 Alpha 4

`v0.2.0-alpha.4` prepares the next vid2dataset2 Rust + Tauri alpha release.
This update changes desktop release packaging and signing.

## Desktop distribution

Release artifacts target macOS ARM64, Windows x64, and Linux x64. macOS Intel
(x64) builds are discontinued.

macOS alpha builds use ad-hoc code signatures. Windows alpha builds are
unsigned. Stable macOS and Windows releases require signing and signature
verification.

Packaged applications include redistributable LGPL-compatible FFmpeg and
ffprobe binaries. Release artifacts include SHA-256 checksums.

## Known limitations

- This is an alpha release and is not a signed stable production release.
- Hosted web/server processing is not included.
- COCO and YOLO annotation exports are deferred; the app writes image outputs
  and traceability manifests.
- Source builds require Rust, Node.js/npm, Tauri system prerequisites, and
  FFmpeg/ffprobe available through explicit paths, environment variables, or
  `PATH`. Packaged desktop builds include their own media tools.
